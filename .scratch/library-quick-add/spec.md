# 动作检索台快捷加入

## 目标

- 新建训练日弹窗占位文字改为 `胸/背/肩/腿`。
- 动作检索台搜索框内提供清空图标，仅输入非空时展示；清空关键词后立即更新匹配结果、数量与分页，保留器械及部位筛选。
- 每张动作卡片新增独立快捷按钮，不打开详情即可将动作加入训练日。由指定训练日进入时直接加入该日；普通浏览时先选计划和训练日。无可选训练日时提示用户先创建。训练中 `pick=1` 保持原加练流程，不误写计划；按钮在该模式下可直接加入训练草稿。
- 保存失败给出反馈；快捷按钮不冒泡打开详情；详情和既有选择流程不退化。
- 上游 `hasaneyldrm/exercises-dataset` 的哑铃上斜卧推为 ID `0314`、英文 `dumbbell incline bench press`；已在发布目录中，展示名 `上斜哑铃卧推`，本轮不改名或数据。

## 验收

- 指定训练日、普通浏览选训练日及训练草稿三种入口分别验证，数据使用目录 ID、中文名和器械原值，默认处方沿用详情加入逻辑。
- 搜索清空不清除其他筛选，筛选条件与结果同次提交；输入为空时不显示清空按钮。
- Node 测试、语法检查和 `git diff --check` 通过；不运行生产构建。
