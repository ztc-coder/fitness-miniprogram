# 04: 训练档案与历史详情支持双主题

**What to build:** 用户选择浅色后，可在统一外观中查看训练统计、动作趋势、历史时间线及单场训练详情；切换 tab、筛选动作或往返详情时主题保持一致，历史训练事实及统计口径不受影响。

浅色采用已确认的 C 方向精修 v2：灰白页面、白色卡片、炭黑主文字、深绿状态与选中项；历史柱使用冷灰 `#879197`，最新 PR 保留亮绿 `#C3ED42`。深色颜色、布局排版和交互逐项保持当前行为。

**Blocked by:** 01: 主题切换闭环：我的、今天与原生导航。

**Status:** ready-for-agent

- [ ] 训练统计卡片、档案页签、同步状态、加载、空状态和错误提示完整适配浅色，数值及单位层级清晰。
- [ ] 动作趋势选择、指标入口、坐标刻度、网格、柱值、日期和 PR 标记均适配；历史柱为冷灰 `#879197`，最新 PR 保留亮绿，文字与描边可辨。
- [ ] 历史时间线、近期场次、日期、动作数、时长及容量适配两套主题，点击与滚动行为保持不变。
- [ ] 单场训练详情中的动作、组成绩、合计和历史兼容展示使用当前主题，包括空数据及本页自有弹层。
- [ ] 改变主题并返回已打开的档案或详情时，当前页签、动作选择及既有展示状态不被主题逻辑重置；新页面也读取当前偏好。
- [ ] 不改变容量、自重次数、连续训练、本月统计、历史分页和本地记录合并口径，不迁移或重写历史记录。
- [ ] 相关记录与详情回归通过；记录统计到趋势、历史时间线、单场详情及返回的完整原生验证，保留暗色颜色回归证据及未覆盖边界。
- [ ] 本票只维护记录流程拥有的展示；若入口会打开共享动作详情，全站验收时联合 02 核对，不重复实现共享组件主题。
