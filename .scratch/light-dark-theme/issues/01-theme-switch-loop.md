# 01: 主题切换闭环：我的、今天与原生导航

**What to build:** 在「我的 → 训练偏好」增加「浅色模式」开关，一次操作立即切换外观并保存在本机。今天、我的、导航栏和底部 tabBar 完整响应，重启后恢复选择；提供其他页面可复用的主题接入方式，保留原有页面生命周期和业务行为。

采用用户已确认的 C 方向精修 v2 浅色设计：页面底色 `#F5F6F7`、白色卡片、炭黑 `#20262B` 主文字与主按钮、亮绿 `#C3ED42` 按钮文字与完成反馈、深绿 `#3E5429` 状态及选中导航、浅绿 `#F2F6E8` 选中底色与 `#A7B68F` 边框。头像为炭黑底亮绿字。深色逐值沿用当前产品实际颜色，不采用设计原型中的另一套深色色值；不扩展多款强调色，不自动跟随系统。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] 「浅色模式」位于「我的 → 训练偏好」，无选择记录时关闭，默认深色；开启为浅色，关闭恢复当前深色。
- [ ] 手动选择立即生效并保存在本机，退出重进后恢复；与重量单位、离线模式等已有偏好互不覆盖。
- [ ] 今天与我的，包括空状态、恢复训练入口、月训练圆环、头像、设置行及自有弹层，符合已确认浅色色彩语义。
- [ ] 浅色主按钮为炭黑底亮绿字，导航与状态使用深绿；保留当前布局、字体、字号、字重、间距、圆角和业务交互，除新增开关外不重排页面。
- [ ] 原生导航栏、状态栏文字、窗口背景与 tabBar 文字、背景、分隔线及选中／未选中图标同步切换；深色使用现有颜色和图标。
- [ ] 从设置页切换后，已打开页面再次显示及新打开页面都获得当前主题；不覆盖原生命周期，不造成重复业务请求或监听器累积。
- [ ] 提供供后续票复用的颜色和主题状态接入方式，核验自定义组件的主题传递；本票不要求提前完成其余业务页面的细节适配。
- [ ] 核验微信原生弹窗、操作菜单、picker 等控件可设置的颜色及平台限制；无法匹配手动主题的部分明确记录为未覆盖或阻塞，不擅自替换业务控件或声称全站已通过。
- [ ] 有运行证据覆盖默认值、双向切换、重启恢复、页面往返、原生栏和图标；相关自动检查通过，记录原生运行环境及未覆盖边界，不执行未获要求的生产构建。
- [ ] 默认深色及切回深色的颜色与改动前一致；切换不修改计划、训练草稿、历史记录或提交队列。
