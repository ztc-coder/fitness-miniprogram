# 03: 训练打卡、间歇与完成小结支持双主题

**What to build:** 用户选择浅色后，可从开始训练到逐组打卡、暂停／恢复、独立间歇、结束训练和查看完成小结，全程使用一致且可辨的浅色外观。复用统一主题状态，仅适配本流程拥有的界面与弹层；主题变化不改变训练事实或计时行为。

浅色采用已确认的 C 方向精修 v2：炭黑主按钮与亮绿文字，深绿状态文字，当前训练行浅绿 `#F2F6E8`、边框 `#A7B68F`，已完成行底色 `#F7F8F4`，亮绿完成反馈。深色逐值保留当前产品配色，布局排版与业务交互不变。共享动作详情的视觉适配由 02 负责，本票不修改其实现，也不以 02 完成为启动前提。

**Blocked by:** 01: 主题切换闭环：我的、今天与原生导航。

**Status:** ready-for-agent

- [ ] 训练标题、进度、动作卡片、目标与成绩输入、待练／已完成／跳过状态均适配浅色，状态和可点击区域清晰。
- [ ] 当前行、完成行、勾选按钮、禁用态、计时及进度条使用已确认色彩语义；主操作为炭黑底亮绿字，不误用原型深色颜色。
- [ ] 暂停提示、恢复操作、独立间歇的展开／收起、运行／暂停／到时状态、时间调整及相关遮罩适配浅色。
- [ ] 动作操作、加组、跳过剩余、结束确认、保存错误及完成小结等本流程自有界面和弹层完整适配；原生系统控件无法控制的外观明确记录。
- [ ] 有进行中草稿时改变偏好并恢复训练，页面获得当前主题，完成成绩、稳定组 ID、暂停状态和间歇结束时间保持一致；不为切换主题额外重启训练或间歇。
- [ ] 完成小结的完成组数、动作数、时长、负重容量、自重次数和上次同类型对比在两套主题中可读，数据与原口径一致。
- [ ] 保留自由勾选、取消完成、独立间歇、暂停和本地完成提交等既有规则；主题不修改快照、游标推进、历史记录或提交队列。
- [ ] 相关训练状态和页面回归通过；记录待练、完成、暂停、间歇、错误及小结的原生运行证据，并完成暗色颜色回归。
- [ ] 本票可独立验证训练流程自有界面；全站验收时另与 02 联合确认训练中动作详情及动作选择入口的外观一致。
