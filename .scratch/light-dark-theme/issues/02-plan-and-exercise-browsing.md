# 02: 计划编排与动作查阅支持双主题

**What to build:** 用户选择浅色后，可在统一外观中查看计划、编辑循环日、筛选和选择动作、打开动作详情；返回或切回深色时外观与偏好一致。复用已建立的主题机制，完整适配本流程拥有的页面及共享动作详情弹层。

浅色沿用已确认的 C 方向精修 v2：灰白页面、白色卡片、炭黑文字及主按钮、亮绿按钮文字、深绿状态、浅绿选中背景。未出稿页面沿用同套色彩语义；深色颜色、现有布局排版及业务交互保持不变。

**Blocked by:** 01: 主题切换闭环：我的、今天与原生导航。

**Status:** ready-for-agent

- [ ] 计划列表、当前计划、循环位置、展开／折叠、空状态及计划操作弹层完整适配浅色，激活状态不再残留深色专属配色。
- [ ] 训练日编辑中的动作条目、目标输入、增删和排序操作、保存与删除提示在两套主题中均清晰可辨，交互行为保持不变。
- [ ] 动作库中的搜索、七类训练部位筛选、器械筛选、已选动作、加载、无结果及分页状态适配两套主题。
- [ ] 选中底色使用 `#F2F6E8`、边框使用 `#A7B68F`，文字与图标按深绿 `#3E5429` 等已确认色彩语义映射；危险操作与普通操作可区分。
- [ ] 共享动作详情弹层的背景、遮罩、文字、要领、关闭操作和媒体占位随主题切换；由本票统一维护，其他流程不重复实现。
- [ ] 真实示意图与动作演示保留原样及原白底，不反相、不染色；加载失败占位清晰，版权署名保留。
- [ ] 从计划编辑进入动作库再返回，已选动作、未保存编辑和原有导航行为不因主题丢失；其他页面打开共享动作详情时也读取当前主题。
- [ ] 主题改动不影响计划游标、动作筛选归类、分页窗口或媒体加载规则；相关自动回归通过。
- [ ] 记录浅／深两套原生运行验证，覆盖计划到训练日编辑、动作搜索选择及详情的完整流程；与已确认色彩基准核对，保留暗色回归证据及未覆盖边界。
