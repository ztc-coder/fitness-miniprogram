# 全站浅色／深色主题

状态：用户已要求开始实施；在 `feat/light-dark-theme` 集成分支按关联 tickets 推进。

## 已确认决策

- 「主题切换」指浅色、深色两套完整外观；不扩展多款品牌强调色。
- 浅色设计以 `.scratch/huashu-color-only-v2/refined-c/` 为准。
- 深色沿用当前小程序 FORGE 色板，视觉颜色保持不变。
- 覆盖全站页面、组件弹层、图表、原生导航栏及底部 tabBar。
- 未提供设计稿的页面沿用同一套浅色色彩语义。
- 保留现有布局、字体、字号、字重、间距、圆角和业务交互。
- 无本机偏好时默认深色；手动选择立即生效，本机保存，关闭重开仍保留。
- 切换入口放在「我的 → 训练偏好」中，新增「浅色模式」开关；默认关闭，点击一次完成切换。
- 不自动跟随系统外观。

## 浅色设计基准

- 页面底色：`#F5F6F7`；卡片和 tabBar：白色。
- 主文字与主按钮底色：炭黑 `#20262B`。
- 按钮文字、完成反馈：亮绿 `#C3ED42`。
- 状态文字、图标、选中导航、月训练圆环：深绿 `#3E5429`。
- 当前训练行和选中标签：浅绿 `#F2F6E8`，边框 `#A7B68F`。
- 已完成训练行：`#F7F8F4`。
- 历史图表：冷灰 `#879197`；最新 PR 保留亮绿。
- 头像：炭黑底、亮绿文字。

具体颜色以设计目录 HTML 与追加 CSS 的最终计算结果为准；不采用原型自带的深色配色覆盖当前产品。

## 实施前核查

- 检查现有本地偏好、页面生命周期、组件隔离、原生导航和图标接入点。
- 核对微信原生控件的手动主题能力，记录平台限制。
- 用户已通过「开始实施 light-dark-theme」授权按本规格实施。

## 验收目标

- 一次操作切换当前页与原生导航，返回其他已打开页面时外观一致。
- 深色默认值与切换回深色后的颜色均与改动前一致。
- 重启后恢复本机选择，切换不改变训练草稿、间歇、计划、历史记录或提交队列。
- 浅色各页面、弹层、图表和 tabBar 无遗留深色区域；真实动作媒体保留原样。
- 执行项目相关自动检查，并记录原生运行验证与未覆盖边界。
