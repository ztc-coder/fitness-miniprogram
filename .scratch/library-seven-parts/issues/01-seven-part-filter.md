# 01: 七类部位筛选

**What to build:** 训练者按胸、背、肩、手臂、腿、腰腹、臀筛选整个离线动作目录，能多选并与器械、搜索组合；详情显示相同部位归类。

**Blocked by:** None (can start immediately).

**Status:** 完成

- [x] 七类固定顺序，全部目录只归入其中一类；`glutes` 优先归臀、颈归肩、上下臂归手臂、上下腿归腿。
- [x] 结果组内 OR、与器械/搜索 AND，空选和「全部」仍可恢复全部结果；一次提交筛选条件与列表/总数。
- [x] 原始目录字段和英文检索保持不变；复用详情部位与筛选归类一致。
- [x] 相关离线检索、页面交互和数据契约测试通过。
