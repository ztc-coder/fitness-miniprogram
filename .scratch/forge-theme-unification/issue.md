# 范围

用户提供训练表格与间歇面板截图，要求修复错乱，并将其它页面风格统一为已验收的 FORGE 深色。

不修改计划、训练成绩或提交链。保留现有工作区变更。

## 实测根因

微信 `style: v2` 原生按钮默认宽度覆盖单类选择器。训练待练行的勾选／删除按钮实际宽度 184px，挤压重量、次数列至 0px；动作菜单和间歇按钮也受影响。

修复使用页面作用域加类选择器，明确按钮宽度、flex、边距、布局。不是通过缩小数字或隐藏列掩盖问题。

## 实施

- 全局：`app.wxss` FORGE 色板、主次按钮；`app.json` 深色导航与 tabBar。
- 今天：移除进入／离开页面的深浅 tabBar 切换，原生主按钮宽度加固。
- 训练：表格列与行内控制、动作菜单、间歇快捷项／收起／结束按钮宽度加固。
- 后续截图：加练按钮文字贴顶，补齐 flex 居中并与结束按钮等高；连续完成组保留 12rpx 行距，避免绿色圆角行连成一整块。
- 计划、训练日编辑、记录与趋势、记录详情、我的、动作库、动作详情：统一深色、信号绿选中、安静的卡片／分隔、用户可读文案。
