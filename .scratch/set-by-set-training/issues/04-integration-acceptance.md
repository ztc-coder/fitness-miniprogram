## 自动验收

- domain + 训练 `Page` harness + 草稿升级 + 加练 + 记录/统计 + 提交/游标测试。
- 假时间覆盖后台过期、暂停冻结、重复提醒、资源释放、恢复和撤销。
- 执行相关 Jest 套件及全量回归；记录环境性既有失败，不能改无关文件掩盖失败。
- `git diff --check`、修改 JS 的 `node --check`；禁止生产构建。
- 功能逻辑单元完成后派只读 `reviewer` 做聚焦审查，修复 P0–P2 再验收。

## 微信端人工验收

- 真机前台声音/振动/静音、提示音离线、键盘、逐组按钮、动作详情媒体兼容。
- 切后台/锁屏后返回、主动暂停、进程退出恢复、间歇调整、到时单次提醒。
- 2/4 组后跳过剩余、撤销误打卡、全部完成后加练、离线整场完成及重试。
- 显式说明后台准时通知不保证，音频失败仍有页面提示。
- 如具备 URL/启动命令、对应本地设计图和稳定数据，再派 `visual-tester`；否则记录未覆盖，不能凭 Jest 宣称真实 WXML/真机验收通过。
