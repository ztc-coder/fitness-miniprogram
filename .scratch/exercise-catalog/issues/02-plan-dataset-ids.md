# 02: 计划用上数据集 id

**What to build:** 新装的推/拉/腿演示计划里每条动作都是数据集数字 id，中文名和器械原值来自动作库。已经存在的旧 slug 计划读出来时能解析到同一条目录，后续加练和反查不再丢动作。记录趋势仍按动作名聚合；自重容量仍只认器械原值 body weight。

**Blocked by:** 01: 离线全库可检索、可看要领

**Status:** ready-for-agent

- [ ] 新种子计划的 exerciseId 均为数据集 4 位数字，且能在动作库里打开对应详情
- [ ] 原 30 条手译绑定保持（bench-press→0025 杠铃卧推 等），一对多时是常规变体不是史密斯
- [ ] 读取仍含 slug 的旧计划后，这些动作能反查到目录（id 解析 + 名称/器械与目录对齐，组数目标不变）
- [ ] 非 body weight 原值（含 assisted、sled machine）容量仍按重量×次数；body weight 仍按总次数
- [ ] 记录页按动作名选曲线，不因换 id 把同一中文名劈成两条
