# 01: 离线全库可检索、可看要领

**What to build:** 打开动作库就能浏览排除 cardio 后的全量动作（含 stretch），用器械 6 桶和部位 9 类同时筛选，用中英文名/肌群/器械检索。点进可滚动详情弹层看到中文名、英文副标题、中文要领、目标肌群、部位和 Gym visual 署名；媒体未接入时用首字 glyph。从计划或打卡进入可以把该动作加入训练日或本次训练，写入数据集数字 id 与器械原值。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 动作库离线可列出全部非 cardio 条目，列表里没有 cardio
- [ ] 器械筛选为 全部/杠铃/哑铃/绳索/器械/自重/其他，曲杠进杠铃、史密斯进器械、assisted 进自重、壶铃进其他
- [ ] 部位筛选为 背/胸/前臂/小腿/颈/肩/上臂/大腿/腰腹，waist 显示「腰腹」；两维 AND
- [ ] 中文名、英文名、目标肌群中文、器械中文都能搜到对应动作
- [ ] 详情弹层展示 nameZh、英文副标题、instructionSteps、中文目标肌群、署名；无次要肌群；无媒体时 glyph
- [ ] 加入计划/加练写入数据集 id、中文名、器械原值；自重原值默认目标重量 0
- [ ] 动作目录纯模块有 Jest（规模、归并、标签、slug→0025 手译、搜索 AND）；domain 的 volume 用例仍绿
