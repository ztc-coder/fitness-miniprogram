## 1. 产品目标与范围

自己及其他微信用户使用的免费力量训练记录工具；源码可供他人自行部署。不增加支付、社交、私教角色、手机号绑定或账号密码体系。

继续使用 CloudBase，不另建服务器。普通用户使用运营者发布的小程序和云环境；自行部署者使用自己的 AppID、云环境及费用额度，不连接运营者生产数据。开源不等于私人训练数据公开，代码许可也不自动授权动作媒体。

### 首版必做

1. 同意前完整本地训练；同意后静默身份与本人云同步。
2. 云端数据隔离，以及本地缓存与当前身份的归属保护。
3. 同步状态、失败提示、持久重试，不把本地保存称作云端成功。
4. 清除本机数据、联网删除全部个人数据，明确区分结果。
5. 真实隐私说明、使用帮助、安全提示和可用反馈渠道。
6. 可复现部署文档、自动回归及双用户/真机发布验收。

### 延后

- 个人备份导出、备份合并恢复。
- 多设备并发编辑支持、自动生成计划冲突副本。首版仅承诺单设备编辑，界面/帮助明确边界，不宣传无冲突多端协作。
- 独立账号体系、个人资料采集、通知、支付及商业后台。

“不支持并发编辑”不豁免用户隔离，也不允许删除后的旧队列恢复云端数据。

## 2. 身份、隐私与本地模式

### 同意前

- 首次使用及旧版无明确同意记录的安装均按未同意处理，不从已有 openid 或缓存推断同意。
- 不初始化个人云服务、不取身份、不启动同步，不请求远程动作图片/GIF或执行媒体预热。
- 本地创建/编辑计划、开练、逐组记录、结束训练、回看历史继续可用；媒体位置显示本地占位，不阻挡训练。
- 不以同意、手机号、头像昵称作为本地训练前提。

### 同意后

- 明确告知即将处理的数据、用途、保存方式及删除入口，用户主动同意后才启动云能力。
- 使用微信身份静默区分用户，无账号密码登录页。身份获取失败仍可本地训练，不误报同步成功。
- 产品云服务同意与微信平台隐私接口授权分开处理。`wx.getPrivacySetting().needAuthorization === false` 不证明用户已同意本产品云同步，也不证明后台隐私指引配置正确。
- 若使用平台受控隐私接口，按官方指引接入授权与兼容处理；不能只新增 `__usePrivacyCheck__` 就宣称合规。
- 设置里现有“离线模式”必须与实际云能力状态一致，不能继续出现开关不控制行为的情况。

撤回同意入口、停用时在途请求处理和反馈渠道具体形式仍待确认，见第 8 节；实现前补齐，不在本轮替用户决定。

## 3. 用户隔离与数据归属

- 客户端直连数据库时，`plans`、`sessions` 及新增个人数据集合均必须配置本人权限；不得默认全员可读写。
- 云函数拥有管理权限，不能依赖客户端集合权限兜底。每个个人数据操作从 `getWXContext()` 获取可信身份，缺少有效身份时拒绝；不信任客户端提交的所有者字段。
- 云函数执行删除等管理操作时，仅能影响当前本人；不接受其他人的 openid 作为操作目标。
- 本地缓存、草稿、提交队列需带所有者边界；身份不匹配时不展示、不上传旧所有者数据。身份未确定时不可把任意历史缓存自动归入当前用户。
- 首次将匿名本地数据同步到当前微信身份前，清楚展示归属及待同步数据；不静默认领归属未知的旧缓存。
- 个人数据访问继续收敛在数据访问层；页面不复制权限、同步或队列规则。

## 4. 可靠同步的最低承诺

- 训练本地完成规则保持不变：实际成绩先持久化、游标只推进一次；网络失败不丢记录、不重复推进。
- 计划创建、修改、删除与训练记录均有可持久恢复的同步任务；不能仅训练记录重试、计划修改失败后永远丢失。
- 云端读取失败/分页中断时保留本地可用数据并提示未读完整；不能用不完整云结果覆盖尚未同步的本地修改。
- 所有计划及记录读取按实际数据量分页，不以单次 SDK 默认条数作为全部数据。
- 重试幂等：同一训练记录重复上传不产生重复历史；已删除计划不会因旧任务复活。
- “我的”至少区分：仅本地、同步中、待同步/失败、已同步，提供手动重试。只有请求成功且对应任务确认完成才显示成功。
- 单设备编辑为首版边界；不同设备的缓存/旧请求不得作为无条件覆盖新状态的依据。若实现需要最低版本校验，可拒绝过期写入并保留本地待处理数据，不必在首版生成冲突副本。
- 保持训练快照、容量口径、离线打卡及浅深主题等现有行为。

## 5. 删除与清除

### 清除本机数据

- 离线可操作；明确不删除云端，之后重新同步可能下载既有云数据。
- 有未同步数据或进行中训练时明确提示丢失范围并二次确认，不能通过清缓存偷偷取消用户训练。
- 清除范围覆盖本机计划、历史、草稿、待提交队列及相关同步状态；完成后旧任务不得继续上传。
- 偏好与同意状态是否同时重置，实施前在确认文案中明示，不能混淆为“全端删除”。

### 删除全部个人数据

- 必须联网、校验当前身份、二次确认；明确包括本人云端及本机计划、训练记录、草稿和同步任务，不影响其他用户及公共动作库媒体。
- 云端删除先执行并确认完成，再清本地。失败/中断不得显示“全部已删除”，保留可理解的失败状态和幂等重试入口。
- 云端需保留足以拒绝删除前旧任务的最小删除代际/等效屏障；旧设备、延迟请求和旧队列不能重新上传已删除数据。不得把过期任务直接改绑到新代际重传。
- 如需保留防复活所必需的最小技术元数据，必须在隐私说明如实披露用途、范围及保存策略，不把它冒充为所有技术痕迹均已清除。
- 已离线的其他设备无法远程即时擦除缓存；告知限制，设备下次联网发现删除屏障后清理旧数据，不能把“云端已删除”说成离线设备已经物理擦除。
- 删除后用户主动新建的数据不属于旧数据恢复，可正常重新使用；重新开启云服务仍遵守同意状态。

## 6. 帮助、隐私与真实资料

- “我的”提供隐私说明、数据管理、使用帮助及反馈入口，状态和危险操作文案与实际行为一致。
- 隐私说明写明：运营者、真实联系渠道、微信身份、用户主动填写的训练数据、云同步、媒体服务、保存/删除方式及用户权利。
- 不虚构运营主体、邮箱、资质、授权或保存期限；缺真实资料时保留发布阻断，不发布占位隐私政策。
- 安全提示：训练记录工具，不提供医疗诊断；动作示例不能替代专业指导，不适时停止训练。
- 首版反馈方式尚未确认；可选微信原生反馈或真实支持渠道，不新增自建工单后端。

### 必须有证据的验收矩阵

| 场景 | 验收结果 |
|---|---|
| 未同意/拒绝/身份失败 | 能完成本地训练；无身份、同步或远程媒体请求 |
| 主动同意与重启 | 仅在明确同意后启用，状态可持久恢复，不重复注册网络重试 |
| A/B 两个微信用户 | 各自只见本人数据；伪造 ID、猜测文档 ID、调用删除均不能越权 |
| 本地身份不匹配 | 不展示或上传另一所有者缓存、草稿与队列 |
| 离线完成→联网 | 记录不丢、队列清理正确、游标只推进一次 |
| 计划编辑/删除同步失败→重启 | 待同步任务仍在；重试后正确收敛，不被云端旧数据覆盖 |
| 数据超过 SDK 单页上限 | 计划和历史均完整，读取中断不清空本地未同步数据 |
| 响应丢失/重复提交 | 不产生重复记录、不误报成功 |
| 清本机 | 明确云端仍保留；已清任务不继续上传 |
| 全部删除失败/中断/重试 | 不报假成功；仅删除本人；重试幂等 |
| 全部删除后旧设备/延迟任务联网 | 旧数据被拒绝，不复活；其他用户不受影响 |
| 新用户演示计划 | 明确属于当前用户且可编辑/删除，无他人训练记录 |
| 真机核心流程 | 计划→训练→完成→历史，断网恢复、计时/声音/振动与浅深主题无回归 |
| 媒体与反馈 | 授权范围匹配实际公开展示；媒体失败不阻挡训练；反馈渠道可达 |

自动测试覆盖逻辑与页面/云函数边界；至少两个真实微信身份验证云端权限。模拟器、mock 和代码审查均不能替代真实云端隔离与真机证据。

## 8. 待确认与正式发布阻断

### 实施前收敛的细节

- 撤回同意的产品行为：候选为立即停止新增云请求、明确在途结果不等于已撤销，云数据删除单独确认。用户尚未确认，不作为已采纳规则。
- 用户支持渠道：微信原生反馈或真实公开联系方式；原生反馈不替代隐私权益联系渠道。

### 正式发布必须全部解除

- [ ] 用户另行授权代码实施，首版必做项完成并复审。
- [ ] 动作图片/GIF公开使用书面授权，确认主体、范围、期限、云存储分发方式及署名要求；免费/开源/署名均不等于获得授权。
- [ ] 真实运营者与隐私联系渠道，后台《用户隐私保护指引》与代码实际处理一致。
- [ ] 小程序主体、类目、备案及其他平台材料按管理后台实际要求完成；不预设个人主体一定具备所有类目资格。
- [ ] 生产 AppID、环境 ID、集合权限、云函数依赖/版本、环境配额与费用预警核实；不同部署不误连生产环境。
- [ ] 双用户云端隔离、删除防复活、真机关键流程完成，保存日期、版本与结果。
- [ ] 微信开发者工具最终包体及预览检查通过；提审内容与实际发布一致。
- [ ] 人工确认生产部署和提审授权；不以本规格或自动测试代替授权。

不得以“审核时隐藏媒体、通过后恢复”规避版权/审核要求。保留媒体等待授权期间可以做开发验证，不能标记正式可上线。

## 9. 官方资料与适用边界

以下为本轮调研所得官方入口；实施时复核 API、基础库和控制台现状，不直接复制调研中的推断为平台保证。

- [云开发能力](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloud/basis/capabilities.html)：数据库、存储、云函数及用户身份。

- [getWXContext](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloud/reference-sdk-api/utils/Cloud.getWXContext.html)：可信调用身份；服务端管理权限必须自行限制本人范围。
- [隐私协议开发指南](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)、[隐私接口清单](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/miniprogram-intro.html)：不是所有联网调用都属于平台受控隐私接口；本产品选择更明确的同意前本地边界。

- [button](https://developers.weixin.qq.com/miniprogram/dev/component/button.html)：平台隐私同意按钮与原生反馈入口。
- [平台运营规范](https://developers.weixin.qq.com/miniprogram/product)：个人信息处理、删除权、知识产权与审核要求。开源发布另需检查源码及依赖许可证，不以本文件作法律授权证明。
