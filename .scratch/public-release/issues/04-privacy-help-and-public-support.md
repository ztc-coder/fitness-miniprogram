# 04: 隐私说明、使用帮助与公开支持渠道

**What to build:** 用户能从“我的”理解数据如何保存和删除、如何离线训练、首版有哪些使用限制，并通过真实公开联系方式获得支持或提出隐私权益请求。不新增工单后端，也不采用微信原生意见反馈作为本轮支持入口。

**Blocked by:** None (can start immediately).

**Status:** done（机制/说明完成；真实资料与发布仍由第06票阻断）

拆票时已确认采用公开支持联系方式，取代父规格中尚待选择的反馈形式；具体联系方式、真实运营者及隐私资料尚未提供。可先完成配置机制、说明与缺项检测，不得编造对外资料。真实资料核实是第06票的发布硬闸门。

- [x] “我的”提供清晰可达的隐私说明、使用帮助、支持渠道及数据管理指引，支持现有浅深主题和页面返回行为。
- [x] 隐私说明覆盖真实运营者/联系方式、微信身份、用户主动输入的计划和训练数据、云同步、媒体服务、保存/删除方式及用户权利；不得把代码开源当作公开个人数据的理由。
- [x] 说明本地保存不等于云端备份，卸载/清缓存可能丢失未同步数据；首版不支持文件备份恢复或多设备并发编辑，不宣传自动冲突合并。
- [x] 按已确认规则说明：同意前本地可用、撤回停止新增云请求但不自动删除云数据、清本机不删除云端、全部删除需联网及确认；异步和离线设备限制如实说明。
- [x] 提供训练安全提示：记录工具不提供医疗诊断，动作示例不替代专业指导，不适时停止训练。
- [x] 支持入口使用运营者提供的真实公开邮箱或联系方式，并提供适合该渠道的可用联系/复制方式；不虚构地址，不混用未批准的原生反馈替代方案。
- [x] 真实资料未齐时能明确检测并输出发布阻断，不把占位政策、示例邮箱或空联系方式当作已完成的对外隐私支持。配置机制可独立验收，资料到位由第06票核实。
- [x] 给出管理后台隐私保护指引的填写核对项，与实际处理保持一致；平台隐私接口授权与产品云服务同意不混淆，不索取无关手机号、头像或昵称。
- [x] 自动测试验证入口、内容边界、支持渠道配置/缺失处理及主题行为；最终与已实现同步和删除语义的一致性由第05票集成验收。
