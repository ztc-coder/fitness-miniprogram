# 01: 本地可用、同意后启用本人云服务

**What to build:** 用户不登录、不启用云服务也能完成本地训练；主动同意后，通过可信微信身份访问本人计划和训练记录。身份获取失败、缓存归属不明或身份发生变化时，不泄漏或错误上传其他人的数据。继续使用 CloudBase，不引入账号密码、手机号或头像昵称采集。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

本轮仅批准落票，功能实施仍需另行授权。本票负责权限和同意门控的完整闭环，不把用户隔离推迟到最终验收；同期帮助文案由第04票交付。

- [ ] 首次使用、拒绝同意及旧版无明确同意记录时，本地计划编辑、训练、完成与历史回看可用；不初始化个人云服务、不获取身份、不启动同步、不请求或预热远程动作媒体。
- [ ] 同意入口明确说明处理的数据、用途和删除方式；只有用户主动同意后启用云能力。微信平台隐私接口授权状态与产品云服务同意分别判断，不从旧 openid 或平台授权返回值推断产品同意。
- [ ] 重启后正确恢复同意状态，不重复注册网络监听或同步执行器；现有离线开关与实际云能力一致，不保留无效开关。
- [ ] 身份获取失败不阻挡本地训练，不进入未知身份同步，不误报云端成功；用户能理解并重试失败的云服务启用。
- [ ] 计划、历史、草稿及队列具有所有者边界；身份不匹配时不展示、不上传另一所有者数据。首次归属匿名数据需明确展示当前身份及待同步范围，不静默认领归属未知的旧缓存。
- [ ] 客户端数据库权限和云函数均只允许访问本人数据；云函数从可信微信上下文取得身份，缺失或无效时拒绝，不信任前端传入的所有者字段。
- [ ] 权限配置与实际查询方式兼容；提供可复现的配置说明。伪造所有者、猜测他人文档 ID、无身份调用均不能绕过权限。
- [ ] 同意后保留现有媒体体验及署名；媒体加载失败不阻挡训练。媒体公开授权仍为正式发布阻断，本票不声称解决版权问题。
- [ ] 自动测试覆盖未同意零云请求/零远程媒体请求、同意及重启、身份失败、缓存归属不匹配、越权请求拒绝；现有训练、主题与快照规则无回归。真实双用户云端验证由第05票记录。
