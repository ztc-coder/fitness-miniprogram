# 02: 计划与训练记录可靠同步

**What to build:** 用户离线修改计划或完成训练后，数据立即本地成立；联网或重启后能可靠重试，并明确看到仅本地、同步中、待同步/失败和已同步状态。网络中断、响应丢失、云端旧数据均不会造成静默丢失、重复训练记录或重复推进游标。

**Blocked by:** 01 — 本地可用、同意后启用本人云服务。

**Status:** ready-for-agent

首版只承诺单设备编辑，不增加冲突副本、文件备份恢复或完整多设备并发合并。该限制不允许过期请求无条件覆盖新状态。

- [ ] 计划新建、修改、删除和训练完成均先持久保存到本地；未同意云服务时保持仅本地，不伪装成云端待上传成功。
- [ ] 启用云服务后，两类数据均有持久同步任务；断网、失败、进程退出及重启不会丢失任务。网络恢复与手动重试可继续执行，不制造并行重复提交。
- [ ] 同一训练记录重复提交、服务端成功但响应丢失后重试，不产生重复历史；训练实际成绩先落盘，游标只推进一次。
- [ ] 云端旧状态、读取失败或分页中断不清空或覆盖本地待同步修改；计划和训练历史超过单页上限仍能完整读取，不以默认返回条数冒充全部数据。
- [ ] 已删除计划不会因读取旧数据、延迟请求或旧任务重试而复活；过期写入被拒绝时保留用户本地修改并给出可理解的待处理状态，不静默丢弃或覆盖。
- [ ] “我的”可查看两类数据的同步状态、失败及待处理任务，并手动重试。只有对应任务获云端确认才标已同步，不把仅本地保存当云端成功。
- [ ] 开始提交与处理异步响应时均遵守当前同意及所有者边界，不将旧请求结果写入另一身份的数据；为第03票的停用、清除和删除提供可验证的任务失效边界。
- [ ] 自动测试覆盖两类任务的失败后重启、响应丢失、重复重试、完整分页/中断、旧云数据、过期写入和计划删除防复活，并验证状态显示与手动重试。
- [ ] 训练过程不引入逐组云写入；不可变快照、容量口径、本地完成、主题及现有训练回归保持通过。
