# 06: 人工解除阻断并确认发布

**What to build:** 维护者核实版权、真实隐私资料、平台资格与生产配置，明确判断是否具备正式发布条件；只有阻断全部解除且获得独立授权后，才执行生产部署和提交审核。

**Blocked by:** 05 — 独立部署与发布专项验收。

**Status:** ready-for-human

授权获取、资料收集和平台资格核查可提前并行准备；本票的最终放行依赖第05票完成。保留现有媒体是用户已确认的选择，未授权时不得改成“发布时隐藏”或擅自移除后宣称已放行。

- [ ] 取得动作图片/GIF公开使用书面授权，核对授权主体、实际展示/分发方式、期限、分辨率、署名及云端存储范围。免费、开源、署名、媒体已上传均不能替代授权；无有效授权保持阻断。
- [ ] 由维护者提供并确认真实运营者、公开支持联系方式和隐私权益联系渠道，验证可达；不能使用测试数据或占位资料对外发布。
- [ ] 后台用户隐私保护指引与产品实际处理一致，包含防复活必需元数据的真实处理说明；缺资料、虚假删除承诺或未经批准的新采集均不能放行。
- [ ] 按管理后台实际要求核实主体、类目、备案及其他资质材料，不预设免费或个人主体可豁免。
- [ ] 确认生产 AppID、环境 ID、权限、云函数依赖/版本、资源配额、费用预警及支持配置；生产与开发/自行部署环境不误连，不把生产凭据提交源码。
- [ ] 核对源码与依赖许可证及第三方内容权利范围，区分源码开源许可与动作媒体许可，不把私有训练数据纳入开源内容。
- [ ] 第05票真实双用户、删除防复活、真机和最终包体验收有可追溯证据，未验证项或P0–P2问题不得默认为通过。
- [ ] 提审内容与实际发布一致，不通过审核期间隐藏媒体、通过后恢复等方式绕过版权或平台审核。
- [ ] 维护者另行明确授权生产部署、提审与发布操作；本轮落票不构成操作授权。未授权时状态保持待发布，不触发生产操作。
- [ ] 记录最终放行人、日期、版本和未关闭风险；只有全部必要条件满足才标记具备正式发布条件，不擅自关闭父 issue。
