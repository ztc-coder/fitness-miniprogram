任务标识：userconfirmed-ui-refinement；串行模式，基于 `feat/public-release` 的 `2aeb8a4`。不提交、不推送、不构建、不调用真实云环境。

## 已确认选择

- 沿用原生 FORGE 与现有浅/深主题，不增加设计方案或 HTML 原型。
- “我的”保留本月训练、训练偏好和关于；技术队列明细、网络行、裸大按钮收敛为云同步卡片与独立数据管理入口。
- 云同步为正向开关；显示仅本地、启用失败、同步中、待同步或已同步，依据现有队列状态，不以本机保存冒充云端确认。失败仅显示“重试云服务”，待同步且服务可用才显示“重试同步”。
- 独立数据管理页采用系统导航返回：常规卡片分清撤回、清本机、本人云端全量删除的范围；未完成删除才显示继续/检查其他设备入口，有屏障且服务可用、无本机删除任务时才显示重新使用入口。
- 首次启用仍询问本机记录归属；取消不丢失匿名数据。在数据管理页，仅当服务可用且匿名计划/记录/草稿仍存在时显示“同步本机记录”。两页复用同一个小型 UI 确认模块，原有身份、epoch、本机版本和删除代际检查不变。
- 所有危险操作保留二次确认；本人身份仅在安全确认中展示。另一设备恢复确认不再展示任务标识与代际数字，保留范围、在途、离线设备与元数据限制。确认期间防止重复发起，取消或原生弹窗失败释放忙状态。

## Review finding 修复（同一未提交工作区）

任务标识沿用 `userconfirmed-ui-refinement`，串行执行，仍基于 `feat/public-release` / `2aeb8a4`。

- **P1 同步成功误报**：成功标题前检查当前所有者的删除任务/同步屏障，以及匿名数据预览。有未完成处理显示「待处理 / 有未完成的数据处理，请到数据管理继续」；本人队列为空但匿名记录未归属时显示「待处理 / 本机还有记录未加入云同步」。不遍历其他身份推断状态，不增加技术标识/错误次数展示，数据管理卡片入口保留。
- **P2 不完整读取不可见**：计划或训练读取失败显示「部分云端记录未加载」与「重新加载」，空队列也不再显示已同步。首次历史读取结束后重新计算提示；专用加载方法重试历史、必要时重试失败的计划读取，同时更新月统计，不递归调用 onShow，也不额外调用可能修复写存储的 queue.getStatus。重试期间禁用按钮，未同意时不新增云请求；上传队列确认与读取完整性仍分开表达。
- **P2 冷启动找不到旧删除任务**：仅身份未知时增加「检查未完成的删除」卡片，解释「如曾删除中断，联网确认本人后继续」。只执行删除用途授权与本人本机任务检查，不调用远端状态检查或新删除，不启用产品同意/上传。无本人任务显示「未发现本机待处理的删除」；有任务才显示原有继续/检查操作，其他身份及匿名数据不变。
- **卸载保护**：数据管理页增加独立于身份 epoch 的页面存活代次，迟到授权、检查结果与原生两级确认不再更新已卸载 UI 或继续清本机；卸载释放忙标志，不调用 setData。共享归属确认在弹窗和云检查返回后均校验页面存活。我的页也对迟到读取/授权与队列 UI 回调增加卸载检查。
