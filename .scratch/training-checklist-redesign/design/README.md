# 训练模块视觉稿

## 设计方向

先完成可审阅视觉稿，再接入小程序业务。文件 `index.html` 是独立浏览器原型，不读写真实训练数据。

颜色：深墨绿 `#0c1613` 为底，`#14211c` 为内容面，`#22352b` 为输入面，`#3ddc97` 为行动与完成态，`#eef5f1` 为文字，`#ffb020` 为间歇提示。

字体：苹方／系统中文黑体用于标题和说明；SF Mono／系统等宽字体用于重量、次数与时间。标题 28–34px，动作名 16–18px，成绩 18px；正文左对齐，计时数字居中。

布局：今天页用开放式训练日信息和一整块主行动区；训练页采用紧凑动作卡片与横向组表；完成页用成绩清单与训练回顾。间歇面板是唯一强调环形图形的区域。

```
今天              训练中              休息面板          完成小结
日期 / 品牌       返回 / 时间 / 暂停    当前动作上下文     完成标记
训练日            完成组数 / 进度      大数字进度环       时长 / 完成组数
计划 / 组数       动作 / 组表          时长快捷项         负重容量 / 次数
继续 / 开始       重量 次数 勾选       调整 / 暂停        动作回顾
动作清单          增加组               结束 / 收起        回首页 / 记录
```

审视与取舍：保留已确认的深色绿，不增加装饰渐变、大幅背景图或满屏标签。首页 DAY 只表达循环位置；组号只表达组序。训练页突出记录表格，减少原版大标题占用。底部计时条和主操作分别占位。

## 预览

- `index.html`：五个状态并排的设计板，桌面可横向滚动。
- `index.html?screen=today`：今天。
- `index.html?screen=training`：逐组记录。
- `index.html?screen=rest`：展开间歇。
- `index.html?screen=mini`：收起间歇。
- `index.html?screen=summary`：完成小结。
- `overview.png`：带页面说明的五屏设计板。
- `today.png`、`training.png`、`rest.png`、`mini.png`、`summary.png`：390 × 844 单屏截图。

本地预览服务：`http://127.0.0.1:8766/`。若服务已关闭，在项目根目录运行 `python3 -m http.server 8766 --bind 127.0.0.1 --directory .scratch/training-checklist-redesign/design`。

原型支持页面切换、数值修改、勾选、增删未完成组、手动开始／暂停／调整／收起间歇、整场暂停、结束确认。数据仅存在当前浏览器页面内存中，刷新重置。首页与完成页使用标注的示例数据，历史对比为展示样例。动作缩略图使用原创器械线稿占位，正式页面沿用动作库媒体。

`rest` 和 `mini` 初始倒计时冻结在 90 秒便于比较截图，点击开始、调整或暂停／继续后运行。原型范围外的动作选择器、跳过／恢复菜单和历史页入口会说明后续接入位置。

## 验证边界

浏览器视觉稿用于确认布局、配色、层级和主要交互。它不代表微信小程序渲染、键盘、安全区、振动、声音、离线恢复与提交链已通过验收。
