# v0.1.0 发布说明

> 状态：**已发布**（2026-10-21）。仓库公开、`v0.1.0` tag 与 GitHub Release 同日落地，见 [票 06](.scratch/release-phase1/issues/06-phase1-release.md)。

## 这是什么

微信原生力量训练记录工具：第 N 天循环计划、逐组打卡、完成历史、离线动作目录、浅深两套主题。动作库为 1,295 条非 cardio 目录，支持关键词（含俗称别名）/ 七类部位 / 器械原值筛选。

## 这个版本包含什么

- **训练**：计划与训练日编辑、逐组打卡、组间休息计时与提示音/振动、完成后写入历史、历史快照不受后续改计划影响。
- **离线优先**：成绩先在本地成立，逐组记录不联网；离线完成进持久队列，联网后收敛为「已全部云同步」。
- **云同步（可选）**：填好自己的云环境后才启用；未配置时启动硬拦截云能力，本地训练、历史与动作库照常可用。
- **隐私边界**：未同意不取身份、不请求远程媒体；撤回同意 ≠ 云删除；清本机 ≠ 全端删除；离线设备不能被即时远程擦除。
- **数据管理**：清本机、全部删除（云确认后才清本地）、删除后重建。

## 已知限制（发布时必须原样保留）

1. **单设备编辑**：不支持多设备并发编辑，也没有自动冲突副本；同时编辑同一份数据可能互相覆盖。
2. **不支持备份导出与合并恢复**（ADR-0012 延后）。
3. **动作媒体不在仓库里**：仓库只有路径字符串（`exercises/images/…`、`exercises/videos/…`），真实图片/GIF 在云存储。版权归 **Gym visual**（须保留 `© Gym visual — https://gymvisual.com/` 与 180×180 限制），**尚未取得书面授权**，因此不随任何发布物分发；未配置媒体根时逐级降级为占位，不阻塞训练。
4. **云同步需要自己的环境**：AppID 在 `project.config.json`，环境 ID 与媒体根在 `config/cloud-env.js`；未填 `envId` 时云能力被禁用（这是设计，不是故障）。
5. **清缓存/重装后可能需要一次协调**：本机代际与云端代际不等时会触发删除屏障，需在「我的 → 数据管理 → 重新使用云同步」连按两次确认；代价是本机未同步数据被清。详见[部署预演记录](deployment-rehearsal.md) 卡点 C。
6. **新身份首次进入会有一条示例计划**「力量循环」（胸三/背二/肩腿），可直接编辑或删除；这不是他人数据。
7. **验收证据仍有缺口**：真机 + 双身份已跑，M01–M22 中 10 行通过、12 行仍 Blocked（未附脱敏截图与设备/基础库版本），见[验收矩阵](public-release-acceptance.md)。
8. **配额与告警、后台《用户隐私保护指引》核对、两设备同时在线**未验证。
