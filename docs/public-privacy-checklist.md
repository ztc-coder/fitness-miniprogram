# 公开隐私说明与支持资料核对（第04票）

本票完成的是配置、缺项阻断和可导航说明机制，不是有效对外政策或整版发布许可。真实资料核实归第06票；代码与第01–03票的最终一致性归第05票。

## 填写与发布前检查

修改 `config/public-info.js`，该文件随小程序公开打包，**只放已批准公开的信息，不放密钥或私人未授权渠道**：

- `operatorName`：真实运营主体/个人运营者的对外名称。
- `privacyContact`、`supportContact`：`label` 填渠道名称（如公开邮箱），`value` 填用户可复制并在该渠道使用的真实地址/联系方式。两者可相同，但必须可达且经过运营者批准。不会自动发送邮件、不创建后台工单、不调用微信原生反馈。
- `antiResurrection.scope`、`antiResurrection.retention`：由第03票提供真实最小元数据范围、用途和保存策略。与其实际集合/字段、删除屏障及清理机制核对后填写；不得凭空承诺固定期限或所有技术痕迹擦除。第03票需把确定结果交第04/06票维护者回填，未确定保持空值阻断。
- `verified`：只有第06票核对真实运营者、渠道可达、保存策略及实际说明一致后置为 `true`，不能用来跳过空字段检查。

运行 `npm run check:public-info`。缺失、常见占位文本或未核实标记将以退出码 1 输出逐项发布阻断。成功仅表示此项静态检查通过，不能证明真实性、合规性或整版可发布；检查器不构建、不部署。不能将 `example.com` 或示例主体填入正式配置。

页面：`pages/help/help`；入口：我的 → 关于 → 隐私说明与公开支持 / 数据管理指引 / 使用帮助与训练安全。缺资料时显示开发说明与发布阻断，联系方式不可复制。资料齐全时支持手动选择文本及复制，复制失败提示手动复制。使用非 tab 标准页面及系统返回，不改导航栈。
