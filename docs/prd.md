## Problem Statement

当前动作详情与精选目录存在三类可见问题：

1. 动作库详情弹层的底部“确认加入当前训练日”操作区会压住或遮挡末尾动作要领，用户无法稳定读完全部步骤。
2. `0238` 的动作语义和媒体均是 cable straight arm pulldown，但中文展示名“绳索直臂下拉”不符合本产品用语，应改为“绳索直臂下压”。
3. 精选目录仍包含 9 个不需要的动作；目录调整后，既有计划可能继续引用已下架动作，CloudBase 也可能残留不再受目录引用的媒体。

## Solution

### 1. 详情弹层不遮挡正文

- 调整共享组件 `components/exercise-detail/`，让标题区、可滚动正文区和底部操作区拥有明确布局边界。
- 当 `showPick=true` 时，正文必须能滚动到最后一条动作要领、备注和媒体署名；底部按钮不得覆盖这些内容。
- 当 `showPick=false` 时，打卡页只读详情继续正常工作，不为不存在的按钮保留异常空白。
- 适配安全区和窄屏；不改变关闭、媒体降级和选择动作行为。

### 2. 修正 0238 展示名

- `0238` 的最终 `nameZh` 固定为“绳索直臂下压”。
- 保留英文名 `cable straight arm pulldown`、`shoulder-extension` 模式、背部标签及现有媒体：
  - `exercises/images/0238-x69MAlq.jpg`
  - `exercises/videos/0238-x69MAlq.gif`
- 展示名必须写入 `scripts/hand-overrides.js` 权威生成链，再由 `scripts/build-exercises.js` 生成目录；不得只手改生成产物。
- “绳索直臂下拉”作为搜索别名保留，避免旧叫法失去可发现性。

### 3. 裁剪 9 个动作并迁移计划

从 `CURATED_EXERCISES` 精确删除以下动作：

| ID | 动作 |
|---|---|
| `0499` | 反向划船 |
| `0573` | 器械山羊挺身（需求原文“器械山羊挺腰”） |
| `0603` | 器械肩推（需求原文“器械推肩”） |
| `0606` | T 杆划船 |
| `0659` | 靠墙俯卧撑 |
| `0688` | 肩胛引体 |
| `2133` | 农夫行走 |
| `2137` | 哑铃阿诺德推举 |
| `3012` | 站姿肩胛后缩撑起 |

- 最终目录从 136 条缩减到 **127 条**；受管媒体目标从 272 个缩减到 **254 个**。
- 同步清理 `scripts/hand-overrides.js` 中这些 ID 的 slug 与 aliases，保证生成器校验通过。
- 计划目录迁移版本从 v3 升到 **v4**。现有计划中的上述动作自动删除；因此变空的训练日和计划沿用既有规则删除；游标指向下一个仍有效训练日。
- 历史 Session 不读取、不改写，继续保留当时动作名称和组数据。
- 不建立 replacement 映射，不自动向计划注入替代动作。

### 4. 无图动作判定与媒体同步

- “有动作图片”的验收标准是最终 127 条目录中每条 JPEG 与 GIF 对应的真实 CloudBase 对象均存在并可被小程序加载，不以路径字段非空代替。
- 仓库自动化继续验证每条动作具有合法、可解析的 JPEG/GIF fileID，并验证 254 个目标集合。
- 真实 CloudBase 检查通过同步脚本列举最终集合；删除只允许发生在 `exercises/images/` 与 `exercises/videos/` 两个受管前缀。
- 本轮 9 个明确删除动作的 18 个媒体对象应成为陈旧候选，不再成为上传目标。
- 若本机缺少媒体源、SDK 或可访问环境，真实对象存在性保持 `ready-for-human`，不得声称已完成；仓库代码与纯函数测试仍须完成。

## User Stories

1. 作为训练者，我想滚动查看完整动作要领，同时保留随时加入训练日的按钮。
2. 作为训练者，我想看到“绳索直臂下压”这一准确名称，并仍能用旧名称搜索到它。
3. 作为训练者，我不想在动作库或现有计划中继续看到已明确删除的 9 个动作。
4. 作为训练者，我想目录升级只清理计划，不改写历史训练记录。
5. 作为维护者，我想媒体目标严格由最终白名单驱动，并能识别 CloudBase 缺失或陈旧对象。

## Out of Scope

- 更换 `0238` 的动作 ID、JPEG 或 GIF。
- 给被删动作建立替代映射或自动加入其他动作。
- 修改历史 Session、训练容量口径或 Plan/Session schema。
- 改变筛选标签、分页大小、媒体版权与署名规则。
