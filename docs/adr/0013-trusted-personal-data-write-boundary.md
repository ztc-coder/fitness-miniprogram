# ADR-0013：私人数据统一经可信云函数写入

- 状态：已采纳；源码已实施，真实云端规则与事务验收未执行
- 关联：[首版范围](../../.scratch/public-release/issue.md)、[同意隔离](../consent-owner-isolation.md)、[可靠同步](../durable-sync.md)

## Context（背景）

客户端“仅本人可写”不能保证未来全量删除后的旧客户端、延迟请求及旧队列遵守删除代际。云函数管理写入也不会自动继承客户端的所有者限制。首版不承诺多设备并发编辑，但必须保留离线修改并拒绝过期写入。

## Decision（决策）

`plans`、`sessions` 与 `personalDataMeta` 应配置客户端全部拒绝读写；产品个人数据仅经 `personalData` 云函数，所有者来自函数内可信 `getWXContext().OPENID`，不接受调用方指定目标所有者。产品云同意独立持久保存，未明确同意不初始化个人云能力或请求媒体。

本地持久任务记录固定操作标识、预期版本及数据代际。服务端采用同一所有者元数据文档作为事务串行点，所有个人写入在事务内检查代际与业务版本；计划删除保留最小墓碑，训练场次不可变且重试幂等。全量删除必须复用该边界推进代际，不能增加绕过该锁的旁路。

## Consequences（后果）

放弃客户端直连以增加云函数调用及同一所有者写争用，换取统一的身份、版本和删除屏障检查。离线训练与逐组记录不依赖联网；过期修改留本地待处理，不自动提高版本覆盖云端，不生成冲突副本或文件备份。

以上规则必须部署并用真实双用户、旧写入及删除竞态验证；源码与 mock 不能证明现有环境已应用权限。SDK 固定版本的事务返回值、缺失读取及提交行为也需实测，见第05票。未授权部署或正式发布。
