# ADR-0011：自由勾选记录与独立间歇

状态：已采纳。规格：[训练清单改版](../../.scratch/training-checklist-redesign/spec.md)。

## Context（背景）

上一轮逐组引导要求开始、完成、自动间歇并顺序推进。用户实际在训练后补记成绩，希望可自由勾选、改数值、增减组，自行决定是否休息。继续将间歇绑定“当前组”和“最近完成组”会使补记或删组意外打断倒计时。

## Decision（决策）

- 新草稿使用 `flowVersion: 2`。完成组和休息控制独立：勾选只改逐组结果，间歇仅由手动入口开始或重启，记录变化不清计时。
- 保留 `pending / completed / skipped` 与稳定组 ID。旧 v1 草稿升级保留真实完成结果和时间状态；旧 active 转回 ready，不能伪造完成。已提交历史不迁移。
- 独立暂停间歇与整场暂停区分：前者允许记录，后者冻结并禁用记录；恢复整场保持原独立暂停。提醒在到时状态成功持久化后执行一次，重启间歇重新允许提醒，不再依赖最近完成组 ID。
- 至少一组完成时允许发起结束。存在待练组须页面确认，再由领域 `prepareTrainingCompletion` 将剩余标记跳过；`finalizeTrainingSession` 继续拒绝 pending，队列无法绕过明确处理步骤。
- 继续使用 ADR-0010 的单一本地完成提交点与重试链。准备结束不先覆盖草稿，完成日志首写失败时保留原待练状态与间歇。
- 小结分别展示负重容量与自重次数；历史总容量兼容字段保留，不将两种单位混加后用于新小结展示。

## Consequences（后果）

记录自由度提高，无法再用当前组证明顺序或推断实际开始时间；训练时长继续是整场真实经过时间。领域测试需覆盖任意组序、取消勾选、跨动作记录与间歇独立；页面测试覆盖确认取消、存储失败和生命周期。浏览器视觉稿验收不能替代微信 WXML、输入法、安全区与提醒验证。
