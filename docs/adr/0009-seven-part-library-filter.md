# ADR-0009：动作库部位筛选改为七类训练部位

- 状态：已采纳；取代 ADR-0008 的九类部位原值筛选决策
- 日期：2026-09-25

上游九类 `body_part` 对应前臂、小腿、颈等细分项，不符合训练者按胸、背、肩、手臂、腿、腰腹、臀浏览的习惯。界面筛选和详情统一使用七类训练部位：`target === 'glutes'` 优先归臀，颈归肩，上下臂归手臂，上下腿归腿；每条动作仅属一类。原始 `bodyPart`、`target`、英文名和器械原值仍保留在离线目录，英文关键词可搜索，器械仍按原值筛选。这样以可理解的导航换取与上游部位原值不一一对应；目录更新时须验证七类完整覆盖且互斥。
