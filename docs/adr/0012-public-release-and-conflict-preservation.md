# ADR-0012：免费公开工具首版采用最小发布闭环

- 状态：已采纳范围；仅规格落地，尚未实施
- 日期：2026-10-17
- 规格：[公开发布 issue](../../.scratch/public-release/issue.md)

## Context（背景）

工具从个人自用扩展为自己及其他微信用户免费使用，并允许他人基于源码自行部署。目标是尽快形成可发布产品，不另建服务器或账号密码系统。此前 CONTEXT.md 和本目录索引引用了不存在的发布规格，摘要包含冲突副本、个人备份等更大范围；本次确认以最小发布闭环为首版目标，不冒充找回旧规格原文。

## Decision（决策）

沿用微信 CloudBase，以可信微信身份隔离个人数据，不增加手动登录墙、手机号或头像昵称采集。同意前本地训练可用，不启动身份、同步或远程动作媒体；同意后才开启云能力。首版补齐本人权限、可靠同步及可见状态、区分本机清除与联网删除全部个人数据、隐私说明及必要帮助反馈。

备份导出/合并恢复、多设备并发编辑与自动冲突副本延后；首版只承诺单设备编辑，但删除前的旧队列/旧设备数据不得复活。该边界优先降低实施与验收成本，代价是首版不提供完整跨设备编辑保障和文件恢复能力。

现有动作图片/GIF保留，等待公开使用书面授权；媒体授权未落实即阻断正式发布，免费和开源不消除版权限制。源码自部署使用各自 AppID 与云环境，不共享生产个人数据。

## Consequences（后果）

ADR-0001 的云开发选择与 ADR-0005 的离线优先原则保留；启动即联网行为需由明确同意门控替代。云权限、删除屏障和数据归属是首版必要可靠性，不因范围收缩省略。撤回同意具体行为与反馈渠道仍待确认，不在此视作已决。

本次仅授权写规格；代码实施、生产部署和提交审核需另行授权。自动测试通过不代表云端部署、真实双用户隔离、真机验收或媒体授权完成。
